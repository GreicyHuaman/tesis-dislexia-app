# Checklist de pulido UX/UI

## Objetivo

Verificar que la aplicación sea clara, consistente y presentable para una demostración académica.

## Pantalla inicial

| Criterio | Estado |
|---|---|
| La pantalla de PIN se muestra correctamente. | Pendiente de validación visual |
| El mensaje de tamizaje educativo es visible. | Pendiente de validación visual |
| El PIN solo acepta 4 dígitos. | Pendiente de validación visual |
| El botón de preparación offline está disponible. | Pendiente de validación visual |

## Evaluación del estudiante

| Criterio | Estado |
|---|---|
| La selección de prueba es clara. | Pendiente de validación visual |
| La prueba de lectura muestra opciones comprensibles. | Pendiente de validación visual |
| La prueba fonológica permite drag/drop sin errores visuales. | Pendiente de validación visual |
| El resumen final muestra semáforo y porcentaje de riesgo. | Pendiente de validación visual |

## Portal académico

| Criterio | Estado |
|---|---|
| El login académico es claro. | Pendiente de validación visual |
| Los reportes cargan correctamente. | Pendiente de validación visual |
| Los filtros son comprensibles. | Pendiente de validación visual |
| El CSV se exporta correctamente. | Pendiente de validación visual |
| El PDF general se exporta correctamente. | Pendiente de validación visual |
| El PDF individual se exporta correctamente. | Pendiente de validación visual |

## Perfil individual

| Criterio | Estado |
|---|---|
| El perfil muestra resumen general. | Pendiente de validación visual |
| El perfil muestra comparación por prueba. | Pendiente de validación visual |
| El semáforo se muestra como badge visual. | Pendiente de validación visual |
| Los estados de carga, vacío y error son claros. | Pendiente de validación visual |

## Panel administrativo

| Criterio | Estado |
|---|---|
| La directora puede acceder al panel. | Pendiente de validación visual |
| Se visualizan estudiantes. | Pendiente de validación visual |
| Se visualizan secciones. | Pendiente de validación visual |
| Se visualizan usuarios. | Pendiente de validación visual |

## Nota de alcance

El sistema debe mantener visible o documentado que corresponde a tamizaje educativo temprano y no a diagnóstico clínico.
