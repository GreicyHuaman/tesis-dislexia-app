# Documentación técnica del prototipo

Este directorio contiene la documentación técnica del sistema de tamizaje temprano de riesgo de dislexia.

## Documentos principales

| Documento | Descripción |
|---|---|
| `arquitectura.md` | Arquitectura general del sistema. |
| `modelo_datos.md` | Modelo de datos y tablas principales. |
| `offline_first.md` | Funcionamiento offline-first y sincronización. |
| `seguridad_privacidad.md` | Seguridad, roles, JWT y privacidad. |
| `api_rest.md` | Resumen de endpoints REST del backend. |
| `pipeline_ml.md` | Flujo de machine learning, dataset y validación. |
| `resultados_validacion_ml.md` | Resultados generados de validación ML. |
| `diccionario_variables_ml.md` | Diccionario de variables del dataset ML. |
| `evidencia_dataset_experimental.md` | Evidencia experimental del dataset. |
| `matriz_validacion_sistema.md` | Matriz de pruebas funcionales del sistema. |

## Alcance

El sistema corresponde a un prototipo de apoyo para tamizaje educativo temprano de riesgo de dislexia en estudiantes de tercer grado de primaria.

Los resultados generados por el sistema no constituyen diagnóstico clínico. La interpretación final debe realizarse por personal especializado.
